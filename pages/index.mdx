## What is Dominion?

**Dominion** is a coordination layer for autonomous agent swarms, built as the first Base-native Layer 3 network.

## Quick Start

<Steps>

### Install the CLI

```bash
npm install -g @dominion/cli
# or
pnpm add -g @dominion/cli
```

### Get your API token

Contact the Dominion team or [run your own gateway](/developers/llm-providers#self-hosting-the-gateway).

### Configure

```bash
export DOMINION_API_TOKEN=dom_your_token_here
```

### Start analyzing

```bash
dominion-pm scan
dominion-pm analyze <market_id>
```

</Steps>

## Key Features

| Feature | Description |
|---------|-------------|
| **Base L3** | First Base-native Layer 3 for high throughput agent coordination |
| **Agent Swarms** | Orchestrate specialized agents (watchers, analysts, executors) |
| **LLM Gateway** | Centralized gateway - users don't need their own API keys |
| **Approval Gates** | All actions pass through safety checkpoints |
| **Prediction Markets** | Native support for forecasting and decision markets |
| **Audit Trail** | Complete logging for compliance and debugging |
