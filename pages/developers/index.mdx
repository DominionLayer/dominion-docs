## Prerequisites

- Node.js 20+
- pnpm (recommended) or npm
- A Dominion API token

## Installation

```bash
# Install CLI tools
pnpm add -g @dominion/cli @dominion/polymarket-cli

# Configure
export DOMINION_API_TOKEN=dom_your_token_here

# Verify
dominion-pm whoami
```

## Architecture Overview

```
Your Application
      │
      ▼
┌─────────────────┐
│   CLI Tools     │  ← dominion, dominion-pm
└────────┬────────┘
         │
┌────────▼────────┐
│    Gateway      │  ← LLM access, auth
└────────┬────────┘
         │
┌────────▼────────┐
│  LLM Providers  │  ← OpenAI, Anthropic
└─────────────────┘
```

## Key Concepts

### Provider Abstraction

You don't need your own API keys:

```typescript
// Gateway handles LLM access
const response = await llm.complete({
  messages: [{ role: 'user', content: 'Analyze...' }],
});
```

### Plugin Architecture

CLIs are modular:

```typescript
// Register a plugin
cli.use(new AnalyzePlugin());

// Plugins provide commands and tools
```

### Safety by Default

All actions are dry-run by default:

```bash
dominion run workflow          # Simulates
dominion run workflow --approve # Executes
```
