# Dominion Network

The Layer 3 blockchain for agent coordination.

## Overview

Dominion Network is the first Base-native L3 optimized for autonomous agent swarms.

## Specifications

| Property | Value |
|----------|-------|
| Type | Layer 3 (on Base L2) |
| Consensus | Proof of Stake |
| Block time | ~100ms |
| Throughput | 10,000+ TPS |
| VM | EVM-compatible |
| Native token | DOM |

## Core Features

### Agent Registry

On-chain registration of agents with:
- Public keys
- Stake amounts
- Role assignments
- Reputation scores

### Prediction Markets

Native support for:
- Binary markets
- Scalar markets
- Conditional markets
- LMSR-based AMM

### Approval Workflows

On-chain coordination for:
- Proposal submission
- Multi-gate approval
- Execution tracking
- Audit recording

### Reputation System

Transparent tracking of:
- Accuracy scores
- Activity volumes
- Violation history
- Trust levels
