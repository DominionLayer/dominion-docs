## Component Details

### Dominion L3

The core blockchain for agent coordination:

- **Consensus**: Proof of Stake (initially centralized sequencer)
- **Block time**: ~100ms
- **Throughput**: 10,000+ TPS
- **VM**: EVM-compatible

### Dominion Gateway

Centralized service for LLM access:

- **Auth**: API key authentication
- **Providers**: OpenAI, Anthropic
- **Metering**: Per-user quotas and rate limits
- **Security**: Key management, abuse prevention

### CLI Tools

User-facing applications:

- **dominion**: General swarm orchestration
- **dominion-pm**: Polymarket analysis

### External Dependencies

| Dependency | Purpose |
|------------|---------|
| OpenAI API | GPT models |
| Anthropic API | Claude models |
| Polymarket API | Market data |
| Base RPC | L2 interactions |
